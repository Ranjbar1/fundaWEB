۲۰ پرسش پایهٔ HTML با پاسخ کوتاه

مرور سریع مفاهیم بنیادی HTML5: از ساختار سند و سی تگ پرکاربرد تا فرم، جدول، تگ‌های معنایی و نکته‌های راست‌به‌چپ. روی هر پرسش کلیک کن تا پاسخ را ببینی.

۰۱ HTML چیست و چه نقشی در وب دارد؟

HTML مخفف HyperText Markup Language (زبان نشانه‌گذاری ابرمتن) است. با این زبان، «ساختار و محتوای» صفحه تعریف می‌شود: عنوان، پاراگراف، تصویر، لینک، جدول و فرم. مرورگر این نشانه‌ها را می‌خواند و آن‌ها را به صفحه‌ای قابل‌مشاهده تبدیل می‌کند.

۰۲ تفاوت HTML، CSS و JavaScript چیست؟

HTML ساختار و محتوا، CSS ظاهر و چیدمان، و JavaScript رفتار و تعامل را می‌سازد. اگر صفحه را یک انسان در نظر بگیریم: HTML اسکلت است، CSS لباس، و JavaScript حرکت و حرف‌زدن.

ترتیب درست یادگیری و ساخت پروژه: اول HTML معنادار، بعد CSS، و در آخر JavaScript.
۰۳ اسکلت پایهٔ یک سند HTML5 چیست؟

هر سند با اعلان نوع سند شروع می‌شود، سپس تگ <html> که دو بخش دارد: <head> برای اطلاعات سند و <body> برای محتوای قابل‌مشاهده.

حداقل کد: <!DOCTYPE html> + <html lang="fa" dir="rtl"> شامل <head> با <title> و <body> با متن.

۰۴ تگ <!DOCTYPE html> چه کاری انجام می‌دهد؟

نوع سند را به مرورگر اعلام می‌کند و باعث می‌شود صفحه در حالت استاندارد رندر شود. بدون آن، ممکن است مرورگر وارد «حالت سازگاری قدیمی» شود و نمایش صفحه در مرورگرهای مختلف به‌هم بخورد.

۰۵ تفاوت <head> و <body> چیست؟

<head> اطلاعات «دربارهٔ صفحه» را نگه می‌دارد: عنوان سند، متادیتا، لینک فایل CSS و اسکریپت‌ها — یعنی چیزهایی که کاربر مستقیم در صفحه نمی‌بیند.

<body> هر چیزی است که در پنجرهٔ مرورگر دیده می‌شود: متن، تصویر، دکمه و فرم.

۰۶ <title> و متا تگ‌ها چه نقشی دارند؟

متن <title> در تب مرورگر و در نتایج جست‌وجو نمایش داده می‌شود و یکی از مهم‌ترین عناصر سئو است.

از متا تگ‌ها: charset="UTF-8" نویسه‌های فارسی را درست نشان می‌دهد، name="viewport" نمایش در موبایل را تنظیم می‌کند و name="description" توضیح کوتاه نتیجهٔ جست‌وجو را تعیین می‌کند.

۰۷ تگ، ویژگی و متن چیست؟

در نمونهٔ <a href="about.html">درباره ما</a>: نام a تگ، href="about.html" ویژگی (با مقدارش) و «درباره ما» متنِ میان تگِ باز و تگِ بسته است.

ویژگی‌ها همیشه داخل تگِ باز و به شکل نام="مقدار" نوشته می‌شوند.

۰۸ تفاوت <div> و <span> چیست؟

<div> یک ظرف بلوکی است (سطر جدید می‌گیرد) و برای چیدمان و گروه‌بندی بخش‌های صفحه به کار می‌رود. <span> درون‌خطی است و فقط بخش کوچکی از متن را در بر می‌گیرد (مثلاً برای رنگ‌دادن به یک کلمه).

هر دو «بی‌معنا» هستند؛ هر وقت تگ معنایی بهتری وجود داشت (مثل nav یا strong) همان را انتخاب کن.
۰۹ سلسله‌مراتب عنوان‌ها h1 تا h6 چگونه است؟

<h1> مهم‌ترین عنوان صفحه (معمولاً فقط یکی) و <h6> کم‌اهمیت‌ترین است.

سطح‌ها را بدون پرش انتخاب کن (h1 ← h2 ← h3)؛ این ساختار هم برای خوانایی انسان و هم برای موتورهای جست‌وجو و صفحه‌خوان‌های نابینایان حیاتی است.

۱۰ لینک چگونه ساخته می‌شود؟

با تگ <a> و ویژگی href: <a href="page.html">متن</a>

target="_blank" لینک را در تب جدید باز می‌کند (همراه با rel="noopener" امن‌تر است)، mailto: ایمیل باز می‌کند و #id برای پرش به بخشی از همان صفحه است.

۱۱ ویژگی alt در تصویر چیست و چرا مهم است؟

alt متن جایگزین تصویر است و برای نابینایان (صفحه‌خوان)، موتورهای جست‌وجو و زمانی که تصویر بارگذاری نمی‌شود خوانده می‌شود.

تصویر صرفاً تزئینی را با alt="" علامت‌گذاری کن و همیشه width و height بده تا صفحه هنگام بارگذاری نپرد.

۱۲ تفاوت <ul>، <ol> و <li> چیست؟

<ul> لیست بدون ترتیب (بولت‌دار) و <ol> لیست شماره‌دار می‌سازد. هر آیتم در هر دو با <li> نوشته می‌شود و لیست‌ها می‌توانند تودرتو شوند.

۱۳ ساختار استاندارد جدول چیست؟

<table> شامل <thead> (سرستون‌ها با <th>)، <tbody> (داده‌ها با <td>) و هر ردیف با <tr>. برای عنوان جدول <caption> و برای دسترس‌پذیری scope="col" روی thها خوب است.

جدول فقط برای «دادهٔ جدولی» است، نه برای چیدمان صفحه. چیدمان با Flexbox و Grid انجام می‌شود.
۱۴ تگ <form> چه می‌کند؟

فرم، ظرف فیلدهای ورودی است و مشخص می‌کند داده «کجا» ارسال شود (action) و «چگونه» ارسال شود (method مثل get یا post). دکمهٔ type="submit" فرم را ارسال می‌کند.

۱۵ پرکاربردترین نوع‌های <input> کدام‌اند؟

text، email، password، number، date، checkbox، radio، file و range.

انتخاب نوعِ درست باعث می‌شود مرورگر هم کیبورد مناسب موبایل نشان دهد و هم فرمت ورودی را بررسی کند.

۱۶ چرا هر ورودی باید <label> داشته باشد؟

<label> با ویژگی for (برابر با id فیلد) به آن وصل می‌شود. نتیجه: کلیک روی برچسب، فیلد را فعال می‌کند و صفحه‌خوان‌ها می‌فهمند هر فیلد برای چیست.

این ساده‌ترین قدم برای «دسترس‌پذیری» فرم‌هاست و تجربهٔ کاربر را هم بهتر می‌کند.
۱۷ اعتبارسنجی داخلی مرورگر چیست؟

ویژگی‌هایی مثل required، minlength / maxlength، min / max، pattern و placeholder بدون حتی یک خط JavaScript ورودی را بررسی می‌کنند.

با این حال، در پروژه‌های واقعی اعتبارسنجی «سمت سرور» را همیشه انجام بده؛ هیچ‌وقت فقط به مرورگر اکتفا نکن.
۱۸ تگ‌های معنایی کدام‌اند و چرا مهم‌اند؟

<header>، <nav>، <main>، <article>، <section>، <aside> و <footer> نقش هر بخش را به مرورگر و موتور جست‌وجو می‌گویند.

مزایا: کد خواناتر، سئوی بهتر، و تجربهٔ بسیار بهتر برای کاربران نابینا — در مقایسه با <div> بی‌معنا.

۱۹ تگ‌های متنی و چندرسانه‌ای پرکاربرد کدام‌اند؟

برای متن: <strong> و <em> (تأکید)، <br> (شکستن خط)، <hr> (جداکننده)، <blockquote> (نقل‌قول)، <pre> و <code> (کد).

برای رسانه: <video> و <audio> (با ویژگی controls)، <iframe> (صفحهٔ توکار) و <details>/<summary> برای بخش جمع‌شونده بدون جاوااسکریپت.

۲۰ در سند فارسی نقش lang و dir چیست و متن‌های دوجهته چگونه درست نمایش داده می‌شوند؟

lang="fa" زبان سند و dir="rtl" جهت نوشتن (راست‌به‌چپ) را مشخص می‌کند. این دو برای دسترس‌پذیری، سئو و نمایش درست فارسی ضروری‌اند.

وقتی در میان جملهٔ فارسی متن لاتین یا عدد داری (مثل </div> یا width: 100%) ممکن است ترتیب نمادها به‌هم بخورد. راه‌حل: آن بخش را با dir="ltr" مشخص کن یا در تگ <bdi> بپیچ تا از متن فارسی «ایزوله» شود.
