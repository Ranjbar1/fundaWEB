چگونه از این دوره استفاده کنیم؟

این دوره برای کسانی نوشته شده که هیچ پیش‌زمینه‌ای از برنامه‌نویسی ندارند. کافی است کنجکاو باشی، یک مرورگر و یک ویرایشگر متن ساده داشته باشی و درس‌ها را به ترتیب پیش ببری.

گام ۱

بخوان و ببین

هر درس با توضیح ساده شروع می‌شود، بعد مثال واقعی می‌بینی و سپس نمونهٔ زنده را امتحان می‌کنی.

گام ۲

دست‌به‌کد شو

کدهای نمایش‌داده‌شده را در فایل خودت تایپ کن. دکمهٔ «کپی» و «اجرا کن» برای تمرین سریع‌تر کنارت هستند.

گام ۳

خودت را بسنج

در پایان هر درس یک آزمونک کوتاه قرار دارد. پاسخ‌ها را بده، نکته‌های توضیحی را بخوان و اگر لازم بود دوباره تلاش کن.

نکتهٔ مهم دربارهٔ راست‌به‌چپ (RTL): این صفحه با dir="rtl" نوشته شده تا متن فارسی درست نمایش داده شود، ولی همهٔ بلوک‌های کد با dir="ltr" و unicode-bidi: isolate از متن فارسی «جدا» شده‌اند. همین کار باعث می‌شود نمادهایی مانند </div> یا width: 100%; در میانهٔ جملهٔ فارسی به‌هم نریزند. همیشه در پروژه‌های واقعی هم همین قاعده را رعایت کن.
پیش از شروع: برای چاپ یا ذخیرهٔ PDF از دکمهٔ بالای صفحه استفاده کن. در نسخهٔ چاپی، سایدبار و دکمه‌ها حذف می‌شوند، رنگ‌ها برای چاپ بهینه می‌شوند و هر درس از یک صفحهٔ جدید آغاز می‌شود.
فصل اول

HTML5 · ساختار و معنای صفحات وب

HTML زبان نشانه‌گذاری است؛ یعنی با آن به مرورگر می‌گوییم «این عنوان است، این پاراگراف است، این دکمه است». در این فصل یاد می‌گیری سند بنویسی، مهم‌ترین تگ‌ها را بشناسی و فرم و جدول بسازی.

۱٫۱

وب چگونه کار می‌کند؟

مرورگر، سرور و سه زبان اصلی صفحه‌های وب

وقتی آدرسی را در مرورگر تایپ می‌کنی، مرورگر یک درخواست به سرور می‌فرستد. سرور فایل‌های صفحه (HTML، CSS، JavaScript و تصاویر) را برمی‌گرداند و مرورگر آن‌ها را به تصویری قابل‌مشاهده تبدیل می‌کند. به این فرایند «بارگذاری صفحه» می‌گوییم.

HTML

ساختار و محتوا

اسکلت صفحه را می‌سازد: عنوان، متن، تصویر، فرم و لینک. بدون HTML اصلاً صفحه‌ای وجود ندارد.

CSS

ظاهر و چیدمان

رنگ، فونت، فاصله، چیدمان و حالت‌های مختلف را تعیین می‌کند. CSS لباسِ تنِ HTML است.

JS

رفتار و تعامل

صفحه را زنده می‌کند: کلیک‌ها، فرم‌ها، منوها، انیمیشن‌ها و هر اتفاقی که با کاربر در ارتباط است.

یک قاعدهٔ طلایی: اول HTML را درست و معنادار بنویس، بعد با CSS شکلش بده، و در آخر اگر لازم بود با JavaScript رفتارش را کنترل کن. این ترتیب، هم یادگیری را ساده‌تر می‌کند و هم نتیجهٔ کارت برای موتورهای جست‌وجو و افراد دارای معلولیت بهتر می‌شود.

۱٫۲

ساختار یک سند HTML5

اسکلت پایهٔ هر صفحه و مفهوم تگ، ویژگی و متن

هر سند HTML از یک «اسکلت» ثابت شروع می‌شود. تگ‌ها با < آغاز و با > پایان می‌یابند و بیشتر آن‌ها یک تگ باز و یک تگ بسته دارند که محتوا میان آن‌ها قرار می‌گیرد.

HTML
<!DOCTYPE html>
<html lang="fa" dir="rtl">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>نخستین صفحهٔ من</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>سلام دنیا!</h1>
    <p>این نخستین صفحهٔ من است.</p>
  </body>
</html>

سه بخش کلیدی

<!DOCTYPE html> به مرورگر می‌گوید با HTML5 روبه‌روست. <head> اطلاعات دربارهٔ صفحه را نگه می‌دارد و <body> هر چیزی است که کاربر می‌بیند.

تگ، ویژگی، متن

در <a href="about.html">درباره ما</a> : نام تگ a، ویژگی href با مقدارش، و متنِ میان تگ‌ها «درباره ما» نامیده می‌شود.

ویژگی‌های مهم در تگ <html>: ویژگی lang="fa" زبان سند را مشخص می‌کند (برای دسترس‌پذیری و موتورهای جست‌وجو مهم است) و dir="rtl" جهت نوشتن را از راست به چپ تعیین می‌کند. اگر در صفحهٔ فارسی بخشی انگلیسی یا عددی دارید که به‌هم می‌ریزد، روی همان عنصر dir="ltr" بگذارید یا آن را در <bdi> بپیچید.
تمرین عملی: یک فایل با پسوند .html بساز، اسکلت بالا را در آن کپی کن، عنوان و متن را تغییر بده و در مرورگر باز کن. سپس کلیدهای Ctrl + U را بزن تا کد اصلی صفحه را ببینی.

۱٫۳

سی تگ پرکاربرد HTML

فهرست مرجع و کاربرد هر تگ، همراه با نمونه

در ادامه سی مورد از پرکاربردترین تگ‌های HTML5 را می‌بینی. لازم نیست همه را حفظ کنی؛ کافی است بدانی هر کدام برای چه ساخته شده‌اند. با تمرین، جایگزینی‌شان به‌صورت خودکار درمی‌آید.

# تگ کاربرد اصلی
۱ <html> ریشهٔ سند؛ همهٔ بخش‌ها داخل آن قرار می‌گیرند.
۲ <head> بخش اطلاعات سند: عنوان، متادیتا، لینک CSS و اسکریپت.
۳ <title> عنوان سند که در تب مرورگر نمایش داده می‌شود.
۴ <meta> توضیحات متا: charset، توضیح صفحه، تنظیمات نمایش در موبایل.
۵ <link> پیوند به منابع خارجی؛ رایج‌ترین کاربرد: اتصال فایل CSS.
۶ <script> قرار دادن یا پیوند دادن کد JavaScript.
۷ <body> بدنهٔ صفحه؛ هر چه کاربر در صفحه می‌بیند اینجاست.
۸ <h1> تا <h6> سرفصل‌ها از مهم‌ترین (h1) تا کم‌اهمیت‌ترین (h6).
۹ <p> پاراگراف متن.
۱۰ <a> پیوند (لینک) به صفحهٔ دیگر، بخشی از صفحه یا فایل.
۱۱ <img> نمایش تصویر؛ همیشه ویژگی alt را بنویس.
۱۲ <ul> لیست بدون ترتیب (bullet‌دار).
۱۳ <ol> لیست ترتیب‌دار و شماره‌دار.
۱۴ <li> هر آیتم داخل لیست‌های ul و ol.
۱۵ <div> ظرف بلوکی بدون معنای خاص؛ برای چیدمان و گروه‌بندی.
۱۶ <span> ظرف درون‌خطی برای شکل‌دهی به بخش کوچکی از متن.
۱۷ <strong> تأکید قوی روی متن مهم (معمولاً پررنگ نمایش داده می‌شود).
۱۸ <em> تأکید ملایم؛ معمولاً کج‌نویس نمایش داده می‌شود.
۱۹ <br> شکستن خط و رفتن به سطر بعد.
۲۰ <table> ساخت جدول داده (همراه با tr، th، td).
۲۱ <form> ظرف فرم؛ ورودی‌ها را گروه‌بندی و ارسال می‌کند.
۲۲ <input> فیلد ورودی با انواع مختلف: متن، ایمیل، رمز، تاریخ و…
۲۳ <label> برچسب فیلدها؛ کلیک روی آن فیلد را فعال می‌کند.
۲۴ <button> دکمه برای انجام عملیات.
۲۵ <textarea> فیلد ورودی چندخطی برای متن‌های بلند.
۲۶ <select> فهرست کشویی انتخاب (همراه با option).
۲۷ <header> سربرگ معنایی بالای صفحه یا بخش.
۲۸ <nav> ناوبری و منوهای اصلی سایت.
۲۹ <main> محتوای اصلی و یکتای صفحه.
۳۰ <footer> پابرگ معنایی: اطلاعات پایانی، لینک‌ها، کپی‌رایت.
تگ‌های مفید دیگر (خارج از این سی مورد): <section>، <article>، <aside>، <figure>، <figcaption>، <video>، <audio>، <iframe>، <details>، <summary>، <hr>، <blockquote>، <pre>، <code>، <mark>، <time> و <bdi>. بعضی از آن‌ها را در درس‌های بعدی خواهیم دید.

۱٫۴

متن، لینک، تصویر و لیست

بلوک‌های سازندهٔ محتوای هر صفحه

سلسله‌مراتب عنوان‌ها

صفحه فقط یک h1 دارد (عنوان اصلی). برای زیربخش‌ها به‌ترتیب h2، h3 و… استفاده کن. این ترتیب هم برای خوانایی انسان و هم برای موتورهای جست‌وجو و صفحه‌خوان‌ها حیاتی است.

HTML
<h1>عنوان اصلی صفحه</h1>
<h2>بخش اول</h2>
<p>این یک پاراگراف است با متن <strong>مهم</strong> و <em>تأکیدی</em>.</p>

<blockquote>«یادگیری با تمرین ماندگار می‌شود.»</blockquote>
<hr>

<h3>لینک‌ها</h3>
<a href="https://example.com" target="_blank" rel="noopener">سایت نمونه</a>
<a href="mailto:info@example.com">ارسال ایمیل</a>
<a href="#top">رفتن به بالای صفحه</a>

<h3>تصویر</h3>
<figure>
  <img src="photo.jpg" alt="توضیح تصویر برای صفحه‌خوان" width="600" height="400">
  <figcaption>توضیح کوتاه زیر تصویر</figcaption>
</figure>

<h3>لیست‌ها</h3>
<ul>
  <li>آیتم اول</li>
  <li>آیتم دوم
    <ol>
      <li>زیرمجموعهٔ اول</li>
      <li>زیرمجموعهٔ دوم</li>
    </ol>
  </li>
</ul>

ویژگی‌های مهم لینک

href مقصد را تعیین می‌کند. target="_blank" لینک را در تب جدید باز می‌کند (همراه با rel="noopener" امن‌تر است). از #id برای پرش به بخشی از همان صفحه استفاده کن.

چرا alt مهم است؟

متن جایگزین تصویر، برای نابینایان، موتورهای جست‌وجو و زمانی که تصویر بارگذاری نمی‌شود خوانده می‌شود. اگر تصویر صرفاً تزئینی است، مقدار آن را خالی بگذار: alt="".

نکتهٔ سرعت: همیشه width و height تصویر را مشخص کن تا مرورگر فضای آن را از قبل کنار بگذارد و صفحه هنگام بارگذاری «نپرد» (پدیدهٔ CLS).

۱ ویژگی alt در تگ تصویر برای چیست؟

۲ target="_blank" چه می‌کند؟

۳ برای نمایش تصویر همراه با توضیح زیر آن، کدام ترکیب بهتر است؟

جدول و فرم

نمایش ساخت‌یافتهٔ داده و دریافت اطلاعات از کاربر

جدول

جدول برای داده‌های جدولی است (نه برای چیدمان صفحه!). ساختار استاندارد آن شامل thead برای سرستون‌ها، tbody برای بدنه و داخل هر ردیف tr، سلول‌های th (سرستون) و td (داده) قرار می‌گیرد.

HTML
<table>
  <thead>
    <tr>
      <th scope="col">نام</th>
      <th scope="col">ایمیل</th>
      <th scope="col">امتیاز</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>سارا</td>
      <td>sara@example.com</td>
      <td>18</td>
    </tr>
    <tr>
      <td>امیر</td>
      <td>amir@example.com</td>
      <td>15</td>
    </tr>
  </tbody>
</table>

فرم

فرم‌ها دروازهٔ ارتباط کاربر با سایت‌اند. هر ورودی باید یک label داشته باشد که با ویژگی for به id همان فیلد وصل می‌شود.

HTML
<form action="/register" method="post">
  <label for="name">نام کامل:</label>
  <input type="text" id="name" name="name" placeholder="مثلاً سارا احمدی" required>

  <label for="email">ایمیل:</label>
  <input type="email" id="email" name="email" required>

  <label for="pass">رمز عبور:</label>
  <input type="password" id="pass" name="pass" minlength="8">

  <label for="birth">تاریخ تولد:</label>
  <input type="date" id="birth" name="birth">

  <label for="city">شهر:</label>
  <select id="city" name="city">
    <option value="thr">تهران</option>
    <option value="sfn">اصفهان</option>
    <option value="shz">شیراز</option>
  </select>

  <label for="msg">توضیحات:</label>
  <textarea id="msg" name="msg" rows="4"></textarea>

  <label><input type="checkbox" name="rules" required> قوانین را می‌پذیرم</label>

  <button type="submit">ثبت‌نام</button>
</form>
نوع ورودی کاربرد
type="text" متن ساده
type="email" ایمیل (مرورگر فرمت را بررسی می‌کند)
type="password" رمز عبور (متن پنهان)
type="number" عدد (همراه با min و max)
type="date" تاریخ با ابزار انتخاب تقویم
type="checkbox" تیک‌زدن چند انتخابی
type="radio" انتخاب یکی از چند گزینه
type="file" انتخاب فایل
type="range" لغزندهٔ مقدار
ویژگی‌های اعتبارسنجی داخلی مرورگر: required، minlength / maxlength، min / max، pattern و placeholder. این‌ها بدون حتی یک خط JavaScript کار می‌کنند، اما در پروژه‌های واقعی اعتبارسنجی سمت سرور را همیشه انجام بده.

۲٫۲

واحدهای اندازه‌گیری

px، em، rem، درصد، vw/vh و توابع محاسباتی

واحد معنا و کاربرد
px پیکسل؛ مقدار ثابت و دقیق. برای حاشیه‌ها و اندازه‌های کوچک خوب است.
em نسبت به اندازهٔ فونت «همان عنصر» (یا والدش). در padding و margin نسبت به فونتِ خود عنصر محاسبه می‌شود.
rem نسبت به اندازهٔ فونت ریشه (html) — پایدارترین واحد مقیاس‌پذیر.
% نسبت به اندازهٔ والد. برای عرض‌ها بسیار پرکاربرد است.
vw / vh یک درصد عرض / ارتفاع «پنجرهٔ مرورگر».
vmin / vmax کوچک‌ترین / بزرگ‌ترین بعد پنجره.
ch عرض تقریبی کاراکتر «۰» در فونت جاری؛ برای عرض ستون متن عالی است.
fr واحد ویژهٔ CSS Grid برای تقسیم فضای باقی‌مانده.
calc() ترکیب واحدها: width: calc(100% - 40px)
clamp() مقدار پاسخ‌گو: font-size: clamp(1rem, 2.5vw, 1.5rem)
pt، cm واحدهای چاپی؛ بیشتر در استایل‌های مخصوص چاپ کاربرد دارند.
CSS
html { font-size: 16px; }        /* مبنا برای rem */

h1   { font-size: 2.25rem; }     /* = 36px */
p    { font-size: 1rem; line-height: 1.9; }
.note{ padding: 1em 1.4em; }     /* نسبت به فونت خود .note */

.hero { height: 80vh; width: 100%; }
.side { width: 25%; }

.box {
  width: calc(100% - 32px);
  margin: 0 auto;
}

h2 {
  font-size: clamp(1.4rem, 4vw, 2.4rem);  /* پاسخ‌گو و روان */
  max-width: 60ch;                         /* طول خط مناسب برای خواندن */
}
قاعدهٔ عملی: برای فونت‌ها تا حد امکان از rem، برای فاصله‌ها از px یا rem، و برای عرض ستون‌ها از درصد یا fr استفاده کن. اگر کاربر اندازهٔ فونت مرورگر را بزرگ کند، متن‌های مبتنی بر rem درست مقیاس می‌گیرند.

مدل جعبه‌ای (Box Model)

محتوا، padding، مرز و margin

هر عنصر HTML یک «جعبه» است. این جعبه از داخل به بیرون چهار لایه دارد: محتوا (content) ← فاصلهٔ داخلی (padding) ← مرز (border) ← فاصلهٔ بیرونی (margin).

CSS
.box {
  width: 300px;          /* عرض محتوا */
  height: 120px;
  padding: 20px;         /* فاصلهٔ داخلی (۴ طرف) */
  border: 4px solid #333;
  margin: 16px auto;     /* فاصلهٔ بیرونی؛ auto برای وسط‌چین کردن */

  box-sizing: border-box; /* عرض/ارتفاع شامل padding و border می‌شود */
}

/* شورت‌هند padding و margin (به ترتیب عقربه‌های ساعت از بالا) */
.box2 { padding: 10px 20px; }        /* بالا-پایین | راست-چپ */
.box3 { margin: 10px 20px 30px; }    /* بالا | راست-چپ | پایین */
.box4 { margin: 8px 12px 16px 20px; }/* بالا | راست | پایین | چپ */

.overflow { overflow: auto; }   /* مدیریت محتوای سرریز */
.outline  { outline: 2px dashed red; outline-offset: 3px; } /* مانند border اما بدون اشغال فضا */
دموی زنده · ابعاد جعبه را تغییر بده
CONTENT
عرض جعبه: — ارتفاع جعبه: — box-sizing: border-box
رایج‌ترین اشتباه مبتدی‌ها: با box-sizing: content-box (حالت پیش‌فرض)، مقدار width فقط «محتوا» را شامل می‌شود و padding و border به آن اضافه می‌شود. به همین دلیل تقریباً همهٔ پروژه‌ها این قانون را در ابتدا می‌نویسند: 
*, *::before, *::after { box-sizing: border-box; }

موقعیت‌دهی (position)

static، relative، absolute، fixed و sticky

مقدار رفتار
static حالت پیش‌فرض؛ عنصر در جریان عادی صفحه و بدون top/right/bottom/left.
relative نسبت به «جایگاه اصلی‌اش» جابه‌جا می‌شود؛ فضایش در سند حفظ می‌شود. معمولاً برای مهار absolute به کار می‌رود.
absolute از جریان عادی خارج می‌شود و نسبت به «نزدیک‌ترین والدِ دارای position» (غیر static) قرار می‌گیرد.
fixed نسبت به پنجرهٔ مرورگر ثابت می‌ماند (مثل نوار بالای همین صفحه).
sticky تا رسیدن به آستانه، عادی رفتار می‌کند و سپس «می‌چسبد» (مثل سرستون جدول‌ها).
CSS
.parent {
  position: relative;      /* مهارکنندهٔ فرزندان absolute */
  width: 100%; height: 300px;
}

.badge {
  position: absolute;
  top: 12px; right: 12px;  /* در RTL: بالا-راست */
  z-index: 10;             /* ترتیب روی هم؛ عدد بزرگ‌تر = جلوتر */
}

.overlay {
  position: fixed;
  inset: 0;                /* top/right/bottom/left = 0 */
  background: rgba(0,0,0,.55);
}

.sticky-bar {
  position: sticky;
  top: 0;
  background: #fff;
  z-index: 50;
}

Flexbox · چیدمان یک‌بعدی

بهترین ابزار برای نوارها، منوها و ردیف‌ها

Flexbox یک «محور اصلی» (main axis) و یک «محور متقاطع» (cross axis) دارد. در حالت flex-direction: row محور اصلی افقی است (و در سند RTL از راست به چپ جریان دارد).

CSS
.container {
  display: flex;
  flex-direction: row;      /* row | row-reverse | column | column-reverse */
  justify-content: center;  /* توزیع روی محور اصلی */
  align-items: center;      /* چیدمان روی محور متقاطع */
  flex-wrap: wrap;          /* اجازهٔ شکستن سطرها */
  gap: 16px;                /* فاصلهٔ میان آیتم‌ها */
}

/* ویژگی‌های آیتم */
.item {
  flex: 1;                  /* flex: 1 1 0 — یکسان بزرگ شود */
  /* یا دقیق‌تر: */
  flex-grow: 1;
  flex-shrink: 0;
  flex-basis: 200px;
  align-self: flex-start;   /* بازنویسی align-items برای این آیتم */
  order: 2;                 /* تغییر ترتیب بصری */
}

Grid · چیدمان دوبعدی

بهترین ابزار برای چیدمان کل صفحه و گالری‌ها

Grid برخلاف Flexbox (که یک‌بعدی است) هم سطر و هم ستون را هم‌زمان مدیریت می‌کند؛ به همین دلیل برای «اسکلت کلی صفحه» ابزار ایده‌آلی است.

CSS
.layout {
  display: grid;
  grid-template-columns: 250px 1fr 250px;  /* سه ستون */
  grid-template-rows: auto 1fr auto;
  gap: 20px;

  /* تعریف ناحیه‌ها (اختیاری اما خوانا) */
  grid-template-areas:
    "header header header"
    "nav    main   aside"
    "footer footer footer";
}
.header { grid-area: header; }
.nav    { grid-area: nav; }
.main   { grid-area: main; }
.aside  { grid-area: aside; }
.footer { grid-area: footer; }

/* الگوهای هوشمند */
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}

.wide-card {
  grid-column: span 2;   /* دو ستون را اشغال کن */
}
.tall-card {
  grid-row: span 2;
}

۳٫۱

متغیرها، انواع داده و عملگرها

نخستین گام‌ها در برنامه‌نویسی

متغیر یک «جعبه با برچسب» است که مقداری در آن نگه می‌داری. در جاوااسکریپت مدرن از const (مقدار ثابت) و let (مقدار قابل‌تغییر) استفاده می‌کنیم و از var (شیوهٔ قدیمی) پرهیز می‌کنیم.

JavaScript
// متغیرها
const name = "سارا";     // رشته (string)
let age = 19;            // عدد (number)
age = age + 1;           // مقدار age حالا 20 است

let isStudent = true;    // بولین (boolean)
let nothing = null;      // نبود مقدار
let unknown;             // undefined

// رشته‌ها
const first = "Hello";
const last = "World";
console.log(first + " " + last);
console.log(`سن ${age} سال است`);   // Template Literal

console.log(first.length);          // 5
console.log(first.toUpperCase());   // HELLO
console.log(first.includes("ell")); // true

// آرایه‌ها
const colors = ["قرمز", "سبز", "آبی"];
console.log(colors[0]);      // قرمز  (شاخص‌ها از صفر شروع می‌شوند)
colors.push("زرد");          // افزودن به انتها
console.log(colors.length);  // 4

// عملگرها
const a = 10, b = 3;
console.log(a + b, a - b, a * b, a / b, a % b, a ** b);
console.log(a == "10");   // true  (فقط مقدار)
console.log(a === "10");  // false (مقدار و نوع — همیشه این را استفاده کن)
console.log(a > 5 && b < 5);   // true
console.log(typeof name); // string

DOM و رویدادها

پیدا کردن عناصر، تغییر محتوا و واکنش به کاربر

DOM (مدل شیء سند) نمایش درختی صفحه در جاوااسکریپت است. با آن می‌توانی هر عنصر را پیدا کنی، متن و سبکش را تغییر بدهی، عنصر بسازی یا حذف کنی و به رویدادها واکنش نشان بدهی.

JavaScript
// انتخاب عناصر
const title = document.querySelector("#title");
const items = document.querySelectorAll(".item");

// تغییر محتوا
title.textContent = "عنوان تازه";
title.style.color = "crimson";
title.classList.add("active");
title.classList.toggle("dark");

// ساخت عنصر
const p = document.createElement("p");
p.textContent = "پاراگراف تازه";
document.body.appendChild(p);

// رویدادها
const btn = document.querySelector(".btn");
btn.addEventListener("click", () => {
  console.log("دکمه کلیک شد!");
});

// رویداد ورودی
input.addEventListener("input", (e) => {
  console.log(e.target.value);
});

// آماده شدن سند
document.addEventListener("DOMContentLoaded", () => {
  console.log("صفحه آماده است");
});

فرم، اعتبارسنجی و پروژهٔ کوچک

همهٔ آموخته‌ها در یک برنامهٔ واقعی

وقتی فرم ارسال می‌شود، صفحه به‌صورت پیش‌فرض رفرش می‌شود. با e.preventDefault() جلوی این کار را می‌گیریم و خودمان منطق را مدیریت می‌کنیم.

JavaScript
const form = document.querySelector("#myForm");
const email = document.querySelector("#email");
const msg = document.querySelector("#msg");

form.addEventListener("submit", (e) => {
  e.preventDefault();                 // جلوگیری از رفرش صفحه

  const value = email.value.trim();   // خواندن مقدار فیلد
  if (value === "") {
    msg.textContent = "ایمیل را وارد کن.";
    msg.style.color = "red";
    return;
  }

  msg.textContent = "ثبت شد!";
  msg.style.color = "green";
  form.reset();                       // خالی کردن فرم
});
پروژهٔ پایانی · فهرست کارها (کاملاً کاربردی)

  • ساخت اولین صفحهٔ شخصی
۲ کار در فهرست
نمایش کد کامل همین پروژه (کلیک کن) 
const form = document.querySelector("#todoForm");
const input = document.querySelector("#todoInput");
const list = document.querySelector("#todoList");
const meta = document.querySelector("#todoMeta");

function updateMeta() {
  meta.textContent = `${list.children.length} کار در فهرست`;
}

form.addEventListener("submit", (e) => {
  e.preventDefault();
  const text = input.value.trim();
  if (text === "") return;

  const li = document.createElement("li");
  li.className = "todo-item";

  const span = document.createElement("span");
  span.textContent = text;

  span.addEventListener("click", () => li.classList.toggle("done"));

  const del = document.createElement("button");
  del.textContent = "حذف";
  del.addEventListener("click", () => {
    li.remove();
    updateMeta();
  });

  li.append(span, del);
  list.appendChild(li);
  input.value = "";
  input.focus();
  updateMeta();
});

list.addEventListener("click", (e) => {
  if (e.target.matches("[data-del]")) {
    e.target.closest("li").remove();
    updateMeta();
  }
});
